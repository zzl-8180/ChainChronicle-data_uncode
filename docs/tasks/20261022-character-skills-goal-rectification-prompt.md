# 给原实施对话的整改提示词：角色技能逐描述、逐效果解析

请在现有项目中实施以下整改。先自行阅读代码、当前页面数据和原始来源，核实问题；不要把此前实施总结或独立审查结论当作无需验证的事实。遵守项目 AGENTS.md，保留已有可靠成果，最小修改现有实现。

## 一、核心目标与完成定义

我的核心目标是：**把角色技能页每条描述包含的各项效果逐一解析出来，让使用者能从描述直接看到对应的数值、单位、条件和证据等级。**

一条描述可能同时包含攻击、防御、移速、暴击率、暴击威力、回复、持续时间、触发条件等多项信息。已经解释其中两项，不等于整条描述完成。请做到：

- 有证据的单项先交付；同句剩余效果始终保留为可追踪的待办。
- 数值、公式、运行时变量、适用对象、触发条件、上限、时长等按实际语义解释；无需为了给出静态倍率恢复完整战斗引擎。
- 确认、类型外推、推断、未知保持区分；不得为追求完成率硬填数值、降低证据要求、把未知置零或把推断改成确认。
- 纯定性机制可以解释其含义并注明“不适用固定数值”，但“不适用”须有依据，不能成为未知效果的兜底分类。
- 页面生成齐全、A 行增加、检查器通过、已经解析若干原始参数，都不能替代“描述各项效果已经对应到答案”的验收。

本轮先完成效果级待办闭环，并实际处理下述已知断点；之后继续按效果级队列推进解析。**机制整改完成与全库技能解析完成必须分别报告。** 剩余研究未完成时如实交接，不宣称总目标完成。

## 三、必须实施的整改

### 1. 建立由当前页面描述驱动的效果账本

复用现有数据结构和生成流程；已有等价字段可以沿用，不强制另造框架。账本至少能表达：

- 输入快照/命名空间、cid、技能类别及槽位、稳定 row_id、原始描述及其内容校验；同号ID跨源不合并。
- 稳定 effect_id、描述中对应的文本片段、效果类型，以及关联的对象/条件/时间；一处公共条件或时长可由多项效果引用，不制造重复效果计数。
- 解析状态：有答案 / 未解决 / 有依据的不适用；有答案另外记录确认、类型外推、推断等证据等级。
- 对应 answer_id 或稳定答案引用，原始记录与字段、原值、换算规则、单位、适用条件及来源证据。需要多个字段共同组成一个答案时保留完整映射。
- 未解决项的具体缺口、候选来源或定位、阻塞原因、可执行下一步、优先级。不能只写“归批6”“以后研究”或仅保留一个无人消费的 hint。

描述的效果拆分尚不能可靠完成时，明确记录“拆分待核查”，保留原句并进入队列；不能把未识别效果当作不存在。不得仅用关键词缺失或答案数量相等证明语义完整。

### 2. 把部分完成行纳入正式待办

剩余工作至少包括：未解析描述、部分完成描述的未解决效果、尚未可靠拆分的描述。不得以 A/C、是否已有答案、是否已有推断标签或是否已晋级为过滤完成的依据。

行级完整度由效果账本派生，独立于原有 A/C 与证据等级。仍有未解决效果或拆分待核查的行必须是部分完成/未完成，不能计作完整描述。全部效果具有合格答案或有依据的不适用结论后，才可计为解析完整；其中有推断时仍须保留推断身份，不能称为全部确认。

待办与当前页面数据一起可重建，并成为看板和下一批选题的实际输入。既有人工核查结果须可持续保留；源描述或依赖证据发生变化时应显式标记需复核，不能盲目沿用完成状态或静默丢失待办。

### 3. 修复已知跨批衔接断点并核对候选

对349、6335逐项核对攻击、防御、移速、两项暴击及时间。沿实际原始链复核 type13 与2012等载体，能安全解释的立即补入逐描述答案；不能解释的保留具体证据缺口和下一条核查路径。仅有原始参数不代表已证明其属于该描述，不能按字段名字硬拼不同命名空间或不同角色的数据。

修复批6与批8/14组合的选择、合并或待办传播规则，使新增单项答案不会抹掉其他未解决效果。尽可能使用通用规则覆盖同类描述；不能仅对两个 cid 手工补丁后宣称闭环。

对筛查候选逐条登记“确认有遗漏并已补齐 / 确认有遗漏仍待解析 / 筛查误报及依据 / 尚待语义核查”等结论。尚待核查项继续进入队列，不将其算作已解决。排除或新增候选均需可对账。

### 4. 同步生成页面、指标和工作入口

由生成器重建受影响产物，不仅手改 HTML/CSV。页面保留已解释效果与证据等级，并清楚呈现同句仍未解释的具体效果；审计细节可折叠，不向读者倾倒实现信息。

看板至少分别统计：描述总数、拆分待核查描述数、完整/部分/未解析描述数、已识别效果数、有答案效果数、未解决效果数、有依据的不适用项数，并单列 Y.G.。证据等级与完整度分开计数，给出各指标定义和分母。

未完成语义拆分时，不把“已识别效果分母”宣传为全库全部效果数或真实总完成率。原文A、C行数、旧候选池扣减可留作辅助历史指标，不能充当剩余效果总量。每批报告实际补齐的效果、完整结束的描述及遗留效果。
