## 接手必读：跨效果尾句与显示比例（2026-11-06）

### 末尾一句可能管前面多项效果

案例：CID350共鸣必杀末句「1stChain以上で必殺技を発動する時に必要なマナが1つ減り、必殺技の威力と反響の威力と回復量と味方にかかる効果が上がる。」同时说明消耗、必杀威力、反响威力、回复量和我方增益。它不是仅作用于紧邻前一句的独立数值效果，也不是整卡所有技能的通用条件。

确认原因：原型曾将段落拆为独立句行，仅在第一句并排显示25/27.5，并用数据库pattern下标生成“第1档/第2档”。这丢失了跨句作用范围，使读者无法知道数值之间的区别。主线其实保留了context_text、binding、effect_binding和note，但原型未将它们用于可见的对应说明。

显示与记录要求：

1. 按同一角色、技能、原文来源及分支边界收集完整上下文；保留原句、row_id、来源位置。不要按相同技能名或相邻句盲目合并。
2. 原文明确的跨效果强化尾句提升到该技能标题下的“强化条件”栏；中文完整句默认可见，日文与逐项数值/待解情况可折叠。保留原行身份，移动展示不复制统计、不删证据。筛选效果时也保留必要条件上下文。
3. 分开记录**文字作用范围**和**数值分支归属**。本句明确涉及五类效果，不等于五类强化数值都已解。不能把27.5/25的比例套给回复、反响或增益；也不能把新分支的值填成基础档。
4. 每个数值应有可读的对应说明与条件跳转。对应仅为推断就显式标推断；无依据则写“条件/对应待确认”，不要用“第N档”伪装已知触发条件。pattern序号不是游戏等级、Chain次数或强弱排序。
5. 数据字段建议：skill的conditionRowId、conditionTitle、conditionScope（原文明示范围）；答案的branchLabel、mappingNote、relatedDescription.rowId，以及完整originalBinding、originalEffectBinding、originalContext。新增展示字段不能升级主线证据级别。

当前实现：`scripts/skill_reader_preview/branch_reading.py`；页面复用原row_id并支持跳转。保守识别本原型已有的1stChain、夜间、沙漠强化尾句；多条竞争条件主动停止，不能宣称已解决全部技能语法。测试见同目录verify.py。
