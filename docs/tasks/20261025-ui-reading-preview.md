## 目标

为普通中文玩家制作一套可直接打开的角色数据库 UI 阅读样稿，用 350、30239、30337 三张卡验证：

1. 角色选择入口与同一模板的三张详情页。

3. 按技能类别分区的中文阅读层，数字紧贴对应效果，同一 pattern 的分支、增益与条件成组。

5. 展开式“计算与来源”，逐项保留 row_id、answer、来源与证据状态。
6. 确认／推断／未知标记；未解效果在对应技能附近可见。
7. 来源按钮支持点击、键盘与手机操作。
