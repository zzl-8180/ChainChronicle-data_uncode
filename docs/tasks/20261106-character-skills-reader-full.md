## 已确认复发原因与避免方法

1. **同原句不等于同正确译文**：协作者不同卡存在冲突译文及自行加值。按完整句定位、剔除外加数字注解并检查数字/单位/关键语义；多份非等价候选不能按文件顺序任选。中文来源不成为解析数值来源。
2. **只数数字不够**：1回耐え曾被译成1HP；5人上限曾被译成5名受益对象；各对象分别承伤10次曾被写成各效果计次。已保留逐句修订和次数/人数单位检查，自动检查仍不能替代完整语义审查。
3. **头尾条件都不能丢**：末尾强化句按技能保留多个独立条件与明确作用范围；句首【仅1次/我方最后排/Chain上下界】也可能是限制。正文复用缓存不保存旧头标签，每次按当前原文单独组合；未知标签整句保持待核。
4. **翻译模板也需复核**：本轮轻量模型曾把ダウン与転倒都译为倒地、漏掉随后、把反射译成先贯穿后反射。已分别使用眩晕/击倒，补回顺序，并将反射明确为可贯穿的反射攻击。不能以正则命中率当语义通过率。
5. **数值展示限定适用域**：30236旧无rule固定解释限本CID；其他卡按自己的规则换算，包含按珠数、按人数连乘、指定职业开局法珠等。无法证明的分支选择不按序号猜普通/强化，不升级主线证据等级。
