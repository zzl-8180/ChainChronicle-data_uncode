## 路径适配

`candidate/scripts/project_layout_paths.py` 分离输入、输出和新元数据定位。无激活配置保持旧路径行为；显式配置必须通过同一原始字节的 SHA 校验，选定模式在进程内固定。不存在的新输入不回退旧 output。源码 ROOT 不重绑定到 live，候选的源码哈希仍读候选源码。相对字段、原始输入、work、旧来源字段和新物理定位分开处理。

解包／媒体45个脚本完成候选适配、AST、读写路由检查及53个新元数据定位点审阅。已知指定缺口又补齐四个历史producer、四个reader Python入口、gold三处读口、四个Node审计入口及三个支持源码依赖；具体变化和各自限制在 remaining-work 与新回执中，未宣称所有候选运行路径穷尽通过。最终统一候选共324份源码／资产文件：322份有基线，其中154份修改，另有Python及Node两个新路径helper；所有Python AST通过。最终只以v4统一代码补丁和check回执为准，中间v1/v2/v3保留不使用。Astra终核纠正了本包的一项证据误判：`scripts/character_skills/card_page_inference_c20_direct_damage_common.py` 实有9处路径hunk，不能称“候选未改／不在补丁”。主线在非重叠行把answer_identity结果转为list；仅此文件已在本包隔离副本按原路径hunks重基，保留主线改动，未写live。原baseline树和旧候选均留证，以新的单文件baseline overlay生成最终v4补丁，主线语义变化不计入本任务差异；当前适用性检查通过、观察漂移为0，不代表未来无漂移。隔离git应用产生CRLF，首次行尾敏感断言失败发生在候选替换前；保留失败回执，归一到原候选LF并核唯一主线delta后才完成重基。早期v1及research自有v3均是其当时版本证据，最终统一状态以root v4为准。发生过一次候选跨写域误改，18文件已按原SHA完整恢复，诊断未删除。主线 card_page_data 在本轮期间继续更新；对比固定在 eb9ba878a3c2061942a08d969fa5fe19ad76ea4cc6d12b09eedfc4afc110ab2b 源快照，保留已出现的C20语义；未来 live 再变必须最小重基，不能用旧补丁覆盖主线新增。

部署配置与默认激活 locator 只有模板，未安装。`configs/deployment-plan.json` 规定先完成物理位置、保护契约和消费者验收，再发布版本化配置与 locator；KEEP写口的 identity mapping 不增加任何写入权限。既有85个共享历史 inode 不得原位重生成或覆盖。
