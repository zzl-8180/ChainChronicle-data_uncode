“继续”是继续投入；“冻结”是停止新增投入并保留现有材料；“放弃独占部分”是接受不再维持该支线的独占能力，仍需先查清共享依赖、列出具体范围并另行决定处理方式。三者都不自动删除文件。下面“已确认”指现有入口文档已记录的关系；未核项不能视作无消费者。

## S1 解包与原生基础

- **价值**：从兼容 APK／缓存得到可读主表和来源记录，是技能研究、图片绑定及未来完整工具分享的基础。[解包入口](../../../projects/unpack/README.md)区分 APK 和缓存来源。
- **已确认输入与消费者**：[缓存 latest](../../../projects/unpack/data/cache/cache_full_latest.json) 指向 v3 的完整 decoded 和 records；[APK 内置主表](../../../projects/unpack/data/apk/base_master/)分源保存。[decode_data5.py](../../../scripts/decode_data5.py)、[decode_cache_snapshot.py](../../../scripts/decode_cache_snapshot.py)产出下游数据；[原生重定位](../../../projects/unpack/research/protection/relocations.json)、恢复镜像、符号与 APK 工作根供解码、媒体及研究使用。
- **未核**：历史恢复试验中哪些具体文件仍是运行闭包、哪些仅用于探索，需按版本和消费者逐项核对。
- **选择后果**：继续可维护解包和兼容版本；冻结保留现有读取和有条件的重跑能力，但不推进新输入；放弃独占探索将失去相应新格式研究、历史复验能力，若连基础一起放弃则影响解码和可复现分享。
- **共享保留**：兼容输入、版本签名、解码器、必要镜像／重定位／符号、完整 JSON 和来源映射。**建议继续基础，冻结没有当前目标的原生探索**：区分运行必要件和研究试验后再评估。

## S2 媒体资产

- **价值**：提供纹理、音频等导出对象，以及角色图片和绑定依据，支持角色页、阅读器及完整资源交付。[媒体入口](../../../projects/assets/README.md)记录覆盖口径和缺口。
- **已确认输入与消费者**：[组合清单](../../../projects/unpack/data/cache/cache_refresh_20261015/composite_inventory.jsonl)、缓存工作副本和共享原生解码器由 [full_unpack_run.py](../../../scripts/full_unpack_run.py)使用；[媒体成果](../../../projects/assets/data/full_unpack/)及[角色图片](../../../projects/assets/data/card_images/)供绑定、名册、角色页和发行使用；正式渲染器维护的 [pages/art](../../../output/character_skills/pages/art/)被阅读器引用。
- **未核**：每份续跑分片、原包和导出对象的独占性与重建成本尚未逐项确认。
- **选择后果**：继续可补齐媒体和绑定；冻结保留已获成果，暂停扩展；放弃独占导出会失去相应资源、来源或重建及续跑能力，具体取决于最终范围。
- **共享保留**：阅读器和卡页使用的图片、绑定证据、来源映射及其路径关系；S1 的共享输入另行保护。**建议冻结扩展，保留现有成果**，按需要继续定向图片工作。

## S3 技能研究与正式生产

- **价值**：把技能描述关联到数值、条件和证据，输出逐卡答案，是当前主线。[研究入口](../../../projects/skill-research/README.md)列出规则和证据。
- **已确认输入与消费者**：S1 主表、[普通效果证据](../../../projects/skill-research/evidence/ordinary_effects/)等供研究；[card_page_data.py](../../../scripts/character_skills/card_page_data.py)调用 [rules.py](../../../scripts/character_skills/rules.py) 的 `answer_for`，使用[正式规则](../../../output/character_skills/profiles/rules.json)，产出[逐卡页面](../../../output/character_skills/pages/)和[账本](../../../output/character_skills/effect_ledger/)，供阅读器使用。
- **未核**：历史证据、backup 和事务成员的逐文件恢复及消费者关系；不能按文件扩展名拆分。
- **选择后果**：继续可增加已证答案；冻结保留当前结果但不推进未知项；放弃独占研究将失去相应解释、追溯或重建能力，放弃正式生产还会影响阅读器更新。
- **共享保留**：rules、对应版本卡页／receipt／backup／`_batch`、campaign、账本和来源证据须作为关联事务处理。**建议继续**，历史大载荷以后按能力和证据单独评估。

## S4 阅读器与展示

- **价值**：让人按角色阅读技能、数值、条件和译文。正式[全库阅读器](../../../output/character_skills/reader_full_20261106/index.html)与隔离试点是不同交付；正式页不会自动同步主线。
- **已确认输入与消费者**：[阅读器代码](../../../scripts/skill_reader_preview/README.md)读取正式 card、campaign、rules、账本，使用 [reference_pairs](../../../output/character_skills/reader_full_20261106/audit/reference_pairs.json)、[reviewed_sentences](../../../scripts/skill_reader_preview/reviewed_sentences.json)和 S2 的 `pages/art`。C20/C21 是隔离同步试点，不能仅凭日期判断已被取代；[B02 候选](../../../projects/reader/site/b02-20261108-v1/index.html)也独立于正式入口。
- **未核**：各试点独有功能、引用和审查材料与正式站的逐项差异；正式页与最新主线是否一致须按回执检查。
- **选择后果**：继续可受控同步和改进界面；冻结保留现有页面但不自动更新；放弃具体试点会失去其独有功能或复验材料，放弃正式阅读器则失去全库浏览入口。
- **共享保留**：正式页及数据、翻译和审定句库、共享图片及相关来源／审查回执。**建议继续正式阅读器，冻结 C20/C21 与其他试点**；比较后再决定各试点独占部分。

## S5 第三方参考分析

- **价值**：将外部资料与游戏原值分源对照，发现差异与候选，也为阅读器提供有来源的译文。[参考分析入口](../../../projects/reference-analysis/README.md)保留各版本分析。
- **已确认输入与消费者**：[第三方原件](../../../其他人的参考/)、[外部采集](../../../raw/external_reference/)和 S1 主表供 [ref_analysis 脚本](../../../scripts/ref_analysis_claude_cc_20261023.py)对照；S4 使用 `reference_pairs`、`reviewed_sentences` 等输入，外部结论须独立核验才可用于正式规则。
- **未核**：各原件与当前译文之间逐文件来源链、各历史分析的其他消费者。
- **选择后果**：继续可开展新对照；冻结保留现有译文、来源和对照但停止扩展；放弃独占分析会失去相应比对与历史复验能力，范围过大还会损及阅读器译文溯源。
- **共享保留**：正式阅读器使用的译文、对照、审定句库及其必要来源；第三方原件按现有保护保留。**建议冻结新增分析**，先明确译文来源闭包，再讨论独占材料。

## S6 机制路线实验

- **价值**：探索可否以机制路线扩大解释范围，为正式研究提供候选；候选不自动成为已证规则。[实验目录](../../../projects/skill-research/experiments/)与[机制优先交接](../../tasks/20261104-mechanism-first-execution.md)记录原范围。
- **已确认输入与消费者**：实验使用解码数据及研究证据，代码包括 [skill_mechanism_trial](../../../scripts/skill_mechanism_trial/)、[skill_mechanism_scale](../../../scripts/skill_mechanism_scale/)和 [skill_route_experiments](../../../scripts/skill_route_experiments/)；正式接收须经当前版本核验。
- **未核**：各实验输入、代码和证据被现行规则、卡页或后续研究实际消费的逐项关系。
- **选择后果**：继续可探索新机制；冻结保留已有候选但不扩大实验；放弃独占部分会失去该路线的试验、复跑和未接收候选，不能推断正式主线不受影响。
- **共享保留**：已进入正式答案或仍被引用的证据、输入和代码，按 S3 版本核对。**建议冻结独立路线**，有具体未解效果时再定向启动。

## S7 旧打包退役支线

- **价值**：保存旧发行实验、隔离复现与历史身份／恢复证据；未来完整分享仍是项目目标，应另建新发行，不自动复活旧流程。[退役归档](../../../operations/history/retired-packaging/20261108/)和[迁移回执](../20261108-packaging-physical-v1/REPORT.md)记录现状。
- **已确认输入与消费者**：归档中的 `share_bundle`、`distribution`、`history-work`保留材料，C14—C18 五个正式隔离入口指向归档；[retirement_runtime.py](../../../scripts/project_layout/retirement_runtime.py)提供只读维护。
- **未核**：归档每个文件的当前消费者和历史复验所需闭包；旧包对未来发行的可复用程度。
- **选择后果**：继续旧包维护会消耗精力；冻结保留历史证据且不推进旧流程；放弃独占部分会失去对应旧包复现或历史身份追溯，不等于放弃未来完整分享。
- **共享保留**：五个隔离入口实际消费的输入、必要源码和恢复证据，以及仍受保护的归档。**建议冻结旧包维护**，未来分享按现行发行要求另行准备。

## S8 布局、存储与事故运维

- **价值**：保持现行路径解析、保护范围和恢复能力可用，并留下迁移与事故的可追溯记录。
- **已确认输入与消费者**：[活动布局配置](../../../scripts/project_layout_active.json)、[路径解析](../../../scripts/project_layout_paths.py)、[存储保留脚本](../../../scripts/storage_retention/)及[运维配置](../../../operations/config/)支撑现行流程；[重跑保护记录](../../tasks/20261113-legacy-rerun-safety.md)记录正式回执和安全重跑边界。
- **未核**：历史实验、工作副本和回执逐项是否仍为恢复或审查所需；静态引用缺失不能证明无依赖。
- **选择后果**：继续运行维护可保持路径和保护有效；冻结重复治理实验保留现状；放弃独占历史实验会失去对应复验或诊断能力，放弃运行代码则可能破坏多个项目入口与恢复。
- **共享保留**：现行配置、解析器、保护清单、恢复器、必要迁移及事故回执。**建议继续运行维护，冻结重复历史实验**，逐项区分运行代码与实验材料。

## 选择表

每行可选“继续／冻结／放弃独占部分”，也可采用右侧的分层建议。这里的放弃仍需后续核依赖、列清单并由用户确定具体处理范围。

建议组合是上表八项：保持解包、数值主线和正式阅读能力，暂缓没有当前目标的探索与重复维护。后续若选择放弃某部分，先识别共享依赖与独占范围，再评估能力损失和可恢复性。

容量仅作定位，不是可释放量：[WizTree 摘要](../20261113-cleanup-research-v1/WIZTREE.md)中 `work` 约 50.072 GiB 涵盖多个项目，不能全部归给某一支线；`projects/assets` 及其 `full_unpack` 等父子项有重叠，不能相加。硬链接、存活副本和归档成本未逐项核实，以上选择不对应空间收益承诺。
